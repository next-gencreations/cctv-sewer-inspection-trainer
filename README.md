# CCTV Sewer Inspection Trainer

**Udemy-style interactive course** for CCTV drain and sewer inspection coding.

## What's included

- **MSCC 5 (WRc)** coding system training
- Structural, Service/O&M, Construction and Miscellaneous defect families
- Interactive knowledge quiz
- Practical CCTV pipe simulator (3 difficulty levels)
- **WinCan-style final inspection sheet** matching the official MSCC Standard Coding Form
- Progress tracking and completion certificate

## How to use

1. Open `index.html` in any modern browser (works offline, mobile-friendly)
2. Work through the curriculum in the sidebar
3. Complete a practical inspection run
4. Generate your WinCan-style report

No server or build step required — pure HTML/CSS/JS.

## Coding standard

Based on the *Manual of Sewer Condition Classification 5th Edition* (WRc). Compatible with WinCan and other MSCC-supporting software.
