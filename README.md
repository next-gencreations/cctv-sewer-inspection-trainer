# CCTV Sewer Inspection Trainer

**Udemy-style interactive course** for CCTV drain and sewer inspection coding (MSCC 5 / WRc) with a practical simulator and WinCan-style final inspection sheet.

**Live repo:** https://github.com/next-gencreations/cctv-sewer-inspection-trainer

## Features

- MSCC 5 coding lessons (Structural, Service/O&M, Construction, Miscellaneous)
- Knowledge check quiz
- Live CCTV pipe simulator (Easy / Medium / Hard scenarios)
- Full **WinCan-style inspection sheet** aligned with the official MSCC Standard Coding Form
- Progress tracking + completion certificate
- Works offline in any modern browser (mobile-friendly)

## Quick start

1. Open **`index.html`** from this repository in Chrome, Firefox, Safari or Edge.
2. Work through the curriculum in the sidebar.
3. Run a practical inspection, then open the WinCan report lesson.

No build step or server required.

## Coding standard

Based on the *Manual of Sewer Condition Classification 5th Edition* (WRc). Codes and the final report form match MSCC observation columns used by WinCan and other compliant software.
